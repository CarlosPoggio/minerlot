# Minerlot

A personal, non-custodial, solo-mining Bitcoin pool for the owner's own
Bitaxe ASIC devices. No external users, no fees, no shared payouts. Runs its
own Bitcoin Core node (pruned) to build block templates trustlessly, and
[public-pool](https://github.com/benjamin-wilson/public-pool) to coordinate
the devices.

Payouts go to the owner's own public Bitcoin address only — private keys and
seed phrases never touch this system.

For full project state, decisions, and next steps, see
[`docs/PROJECT_STATE.md`](docs/PROJECT_STATE.md).
